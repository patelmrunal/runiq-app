# Runiq Privacy Policy

Effective date: 2026-04-13

Runiq helps users track running activity and progress.

## Data We Collect
- Account data such as email address, username, and profile fields.
- Running activity data such as distance, duration, pace, and route/location points during active runs.
- Device-related data such as push notification token and app diagnostics needed for reliability.

## Why We Collect Data
- To provide core app features including run tracking, streak logic, tasks, and profile history.
- To deliver push notifications configured for user experience and run lifecycle.
- To improve reliability, detect abuse, and maintain service quality.

## Background Location Use
Runiq collects precise location data during an active run, including when the app is closed or the screen is off, so route and distance tracking remain accurate. Runiq does not use background location when no run is active.

## Data Sharing
Runiq uses integrated service providers (including Firebase services and ad-related SDK components) to support app operations, analytics, and monetization features where enabled.

## Data Security
Data is transmitted over encrypted channels and stored in managed infrastructure with access controls.

## Data Retention and Deletion
Runiq retains user data while an account remains active or as required for app functionality, legal, and abuse-prevention purposes. Users can request deletion through support channels.

## Contact
For privacy questions or deletion requests, contact: support@runiq.app
